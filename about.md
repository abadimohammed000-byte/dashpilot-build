# DashPilot AI

A local-first Geometry Dash autopilot prototype for Geode. It inspects native player and level-object state, estimates nearby hazards and gaps, and applies mode-specific jump / hold / release rules. F6 arms the bot from the main menu or toggles it during a level; F7 opens the live debug panel.

This is an experimental heuristic controller, not a perfect solver or an embedded ChatGPT integration. Read the included README for compatibility requirements and limitations before building or testing.
